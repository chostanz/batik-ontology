Sebaran Geografis Nusantara

Koridor Kebudayaan & Sentra Produksi Batik

Setiap sentra batik memiliki karakteristik visual dan teknik perintangan malam yang khas, dipengaruhi oleh kondisi geografis dan sejarah akulturasi wilayah.

1. Jawa Pedalaman (Yogya & Surakarta)

Didominasi warna sogan cokelat, indigo nila, dan putih mori. Motif sarat aturan keraton (Parang Barong, Kawung, Sido Asih, Truntum) dengan pakem geometris simetris.

2. Jawa Pesisiran (Pekalongan, Cirebon, Lasem)

Pewarnaan cerah akulturasi Tiongkok dan Eropa. Mengangkat motif flora buketan, mega mendung, burung hong, dan satwa laut dengan garis kontur dinamis.

3. Sumatera (Jambi, Bengkulu, Minangkabau)

Motif ikonik daerah seperti Angso Duo (Jambi), kaligrafi Arab & bunga Rafflesia Besurek (Bengkulu), serta pewarnaan alami rendaman lumpur Tanah Liek (Minang).

4. Kalimantan (Pontianak, Palangkaraya)

Mengangkat kearifan lokal seperti motif Corak Insang sungai Kapuas dan filosofi pohon kehidupan kosmis Batang Garing masyarakat Dayak.

5. Bali & Nusa Tenggara

Mengintegrasikan ornamen ukiran pura, topeng Barong Bali, kembang teratai, serta perpaduan harmoni ritual keagamaan Hindu dan kriya tenun lokal.

6. Papua (Asmat & Jayapura)

Garis ekspresif ornamen ukiran kayu suku Asmat, perisai perang tifa, serta siluet anggun burung Cendrawasih dengan pewarnaan tanah dan terakota.

Motif Larangan Keraton (Awisan Dalem)

Dalam tatanan adat Keraton Surakarta dan Yogyakarta, properti aturanPemakaian membatasi pemakaian motif sakral:

Parang Rusak Barong: Hanya diperkenankan untuk Raja atau Sultan pada upacara kebesaran kenegaraan. Mengandung makna spiritual pengendalian hawa nafsu dan keteguhan kepemimpinan.
Motif Huk: Terdiri atas unsur binatang buas, kerang, dan sayap garuda. Diperuntukkan secara eksklusif bagi keluarga inti raja dan putra mahkota.
Kawung & Parang Klithik: Mengikuti hierarki derajat kebangsawan keraton berdasarkan garis keturunan langsung.

Konteks Ritual Daur Hidup (Lifecycle Adat)

Kelas adat mengklasifikasikan pemakaian motif pada fase transisi kehidupan manusia:

Pernikahan (Sido Asih & Truntum): Motif Truntum melambangkan cinta tulus yang senantiasa bersemi kembali. Motif Sido Asih menyimbolkan harapan agar kedua mempelai saling mengasihi dalam keharmonisan rumah tangga.
Kelahiran (Mitoni / Tingkeban): Motif Pamiluto dikenakan pada upacara 7 bulan kehamilan sebagai doa agar persalinan berjalan lancar dan sang anak berbudi pekerti luhur.
Kematian (Slobok): Ornamen geometris belah ketupat bermakna mempermudah (longgar/slobok) perjalanan arwah menghadap Sang Pencipta secara damai.

Konfigurasi dan Prosedur Eksekusi di Apache NetBeans

Metode 1: Eksekusi Langsung Melalui NetBeans (Run Project / F6)

Proyek ini telah dikonfigurasikan dengan batikgui.BatikServer sebagai main class pada berkas pom.xml dan nbactions.xml.

  1. Buka proyek batik-gui di Apache NetBeans IDE.
  2. Klik tombol Run Project atau tekan tombol F6.
  3. NetBeans mengeksekusi kelas Java BatikServer, memuat berkas ontologi batik-lengkap.rdf via Apache Jena, menyajikan API pada port 8080, dan membuka peramban web secara otomatis.

Metode 2: Eksekusi Mode Pengembang Next.js

Struktur Next.js lengkap tersedia pada direktori kerja untuk keperluan modifikasi komponen secara langsung: 

npm.cmd run dev

Aplikasi Next.js berjalan pada port http://localhost:3000 dengan dukungan hot-reload.

Metode 3: Eksekusi Melalui Maven CLI NetBeans 

"C:\Program Files\NetBeans-24\netbeans\java\maven\bin\mvn.cmd" compile exec:java
